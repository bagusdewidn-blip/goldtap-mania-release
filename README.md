## 📖 Tentang Goldtap Mania

**Goldtap Mania** adalah game kasual *arcade* yang memacu adrenalin dan refleks jari Anda. Kumpulkan koin dan uang emas sebanyak-banyaknya dalam hitungan detik, selesaikan misi harian, dan tukarkan poin kemenangan Anda langsung ke saldo **DANA**.

---

## ✨ Fitur Unggulan

| Fitur | Deskripsi |
| :--- | :--- |
| ⏱️ **Sesi Normal (30 Detik)** | Tantangan refleks cepat dengan sistem hitung mundur (*countdown*) untuk mencetak skor tertinggi sebelum waktu habis. |
| 🔥 **Bonus Session** | Mode spesial berhadiah berlipat ganda untuk mendongkrak perolehan koin secara instan. |
| 🎯 **Misi Harian** | Selesaikan target harian untuk klaim bonus poin tambahan secara rutin. |
| 🎬 **Iklan Berhadiah** | Tonton iklan singkat saat energi habis atau ingin menambah saldo koin ekstra tanpa menunggu lama. |
| 💳 **Dompet & Penarikan DANA** | Kelola saldo koin langsung di dalam aplikasi dan ajukan pencairan hadiah ke akun DANA (mulai dari **Rp 10.000**). |

---

## 🎮 Alur Permainan

1. **Mulai Sesi:** Tekan tombol **PLAY NOW** dari layar utama untuk memasuki arena.
2. **Kejar Waktu:** Kumpulkan skor sebanyak mungkin selama **30 detik** (perhatikan *countdown* 3-2-1 menjelang waktu habis).
3. **Manfaatkan Bonus:** Masuk ke **Bonus Session** atau klaim **Misi Harian** untuk memaksimalkan saldo dompet.
4. **Tarik Hadiah:** Buka menu **Dompet**, pilih nominal penarikan (contoh: `Rp 10.000`), dan pantau status proses pencairan.

## 📲 Panduan Instalasi

1. Kunjungi halaman **[Releases](https://github.com/bagusdewidn-blip/goldtap-mania-release/releases)** di sisi kanan repositori ini.
2. Unduh file installer **`.apk`** versi terbaru pada bagian **Assets**.
3. Buka file `.apk` yang telah diunduh melalui *File Manager* di perangkat Android Anda.
4. Jika muncul peringatan keamanan, aktifkan izin **Instal dari Sumber Tidak Dikenal** (*Install from Unknown Sources*).
5. Ketuk **Instal** dan tunggu hingga aplikasi siap dimainkan.
